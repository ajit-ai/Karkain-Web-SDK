Compatibility
=============

The Karkain SDK targets the Karkain compiler v1.2.0 minimum supported
version with a v1.2.x compatibility target.

* Minimum supported compiler: Karkain v1.2.0.
* Compatibility target: Karkain v1.2.x.
* Supported engines: Go front end and self-hosted ``kcc`` engine where the
  engine is executable on the host.
* Native execution requires a host C compiler (GCC/Clang/MSVC) for the
  C23 backend.

Anything labelled ``Planned`` / ``Not Yet Implemented`` is not part of the
supported API.
